## 💻 Run Locally

### Prerequisites
- Node.js and npm

### Setup

```bash
# Clone the repository
git clone https://github.com/NityaArya30/interview_ai.git

# Move into the project directory
cd interview_ai

# Install dependencies
npm install

# Start the development server
npm run dev
```
